# Bacterial Species Prediction

**Tech:** Pandas, feature engineering workflow, Random Forest, scikit-learn, Streamlit.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

The four numeric columns are arbitrary synthetic features. They demonstrate training and prediction code but do not represent validated bacterial measurements or DNA sequences. For a meaningful project, use a documented biological dataset, explain the feature definitions, split by appropriate biological groups, and report per-class metrics.
